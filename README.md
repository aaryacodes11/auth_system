\# Auth System 🔐



A secure authentication system built with the MERN stack, featuring JWT-based sessions and password hashing.



\## Features

\- User registration with hashed passwords (Bcrypt)

\- Login with JWT token generation

\- Protected routes using JWT verification middleware

\- Persistent login via localStorage

\- Logout functionality



\## Tech Stack

Frontend: React, React Router, Vite

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

Security: bcryptjs (password hashing), jsonwebtoken (JWT auth)



\## Running Locally



Backend:

cd server

npm install

npm run dev



Frontend:

cd client

npm install

npm run dev



The app runs on http://localhost:5173, with the API on http://localhost:5001.
